Backup & restore
Everything in this tool — every project, client, payment, and rate — lives only in this browser. Nothing is stored anywhere else. If this browser's data ever gets cleared, or you switch devices, there's no way to get it back unless you've exported a backup first.
Export a backup
Saves every project, client, payment record, and rate setting to one file. Keep it somewhere safe — email it to yourself, save it to cloud storage, whatever's easiest.
Restore from a backup
This replaces everything currently in the tool with what's in the backup file. Anything created since that backup was made will be lost. There's no undo.
Proof uploads via Google Drive
Connect your Google Drive so uploading a proof creates the folder, uploads the file, sets it to "anyone with the link," and drops that link on the job automatically — no manual copy-pasting.
One-time setup
1. Go to console.cloud.google.com and create a project (or use an existing one).
2. Go to APIs & Services → Library, search "Google Drive API," and click Enable. This is separate from the steps below.
3. Google now walks new projects through a setup wizard called "Google Auth Platform" (Branding → Audience → Data Access → Clients). If you land there, work through it top to bottom.
4. On the Audience step, choose External — you can't switch this later without starting a new project.
5. On Data Access, add the Drive scope. Because Drive access counts as a "sensitive" scope, Google will offer a verification process — skip it. Instead, leave the app in "Testing" mode and add your own Google account (and anyone else who'll use this) under Test users, up to 100 people. That's enough for a tool like this and avoids weeks of review.
6. On Clients, click Create Client → type Web application → under "Authorized JavaScript origins" add the exact URL you open this Dashboard from.
7. Copy the Client ID it gives you and paste it below.
8. Important: this only works if the Dashboard is loaded from a real http(s):// address — opening the file directly from your computer (a file:// path) won't work with Google sign-in at all. It needs to be hosted somewhere, even just the Netlify site you already have.
9. The first time you connect, Google shows an "unverified app" warning — that's expected since you skipped full verification in step 5, click through it.
